# Цепочки целей

Файлы `*.json` этого каталога читает автозагрузка `Objectives` (`objects/objectives/objectives.gd`).

```json
{
  "chains": {
    "<id цепочки>": {
      "final_text": "Текст цели после последнего шага (пусто — цель скрывается)",
      "next": "<id цепочки, которая стартует после этой (необязательно)>",
      "steps": [
        {"id": "<id шага>", "text": "Текст на экране", "done_when": {<условие StateRules>}}
      ]
    }
  }
}
```

- Цепочку запускает сценарий: `Objectives.start(&"opening")`. Активный шаг попадает в `GameState.set_objective`.
- `done_when` — условие в формате `data/terminals/README.md` («Условия»): `flag`, `not_flag`, `access`, `power`, `all`, `any`. Если условие уже выполнено, шаг пропускается сразу.
- `next` — законченная цепочка сама запускает следующую (`opening` → `part2`); так же и после загрузки сохранения, где цепочка уже закончена.
- Прогресс сохраняется вместе с игрой (`GameState` → `objectives`).

## Флаги цепочки `opening`

Часть флагов уже ставят системы: `opening/hero_capsule_open` (капсула героя), `generator_started` (процедура генератора), `senior_key_taken` (ключ старшего), `caretaker_assigned` (протокол преемственности), `module4_ready` (чек-лист поста), `dream/returned/module_4` (выход из сна модуля 4). Флаги переходов между зонами — `opening/left_emergency_block`, `opening/reached_old_core`, `opening/reached_old_control`, `opening/reached_module_4` — ставят зоны-триггеры, когда начало будет собрано в сцене комплекса (пролог). Формулировки целей — тестовые.

## Цепочка `part2` и флаги прогресса части 2

Канон — `docs/game_design/08-part2.md` (#226). `part2` стартует сама, когда закончена `opening` (выход из первого сна, `dream/returned/module_4`). Шаги: вернуться к пульту старого ЦУ → «Восстановить системы» (три направления в любом порядке) → проверить состояние модулей (финал части). Пульт старого ЦУ (`data/terminals/opening_old_cp.json`, экран `recovery_map`) показывает карту восстановления и отмечает законченные направления `[+]`. Формулировки — тестовые.

Список флагов части 2 фиксирован; на них опираются задачи части, межсонье (#228) и монитор. Все флаги логические, ставятся один раз и не снимаются (кроме `part2/n2_trust`).

| Флаг | Что значит | Кто ставит |
|---|---|---|
| `part2/recovery_map` | Смотритель открыл карту восстановления (П2) | Пульт старого ЦУ, экран `recovery_map` |
| `part2/dir_lower_done` | Направление «Нижний контур» закрыто (П3а) | Задача «Нижний контур» |
| `part2/dir_upper_done` | Направление «Верх» закрыто (П3б) | Задача «Верх» |
| `part2/dir_storage_done` | Направление «Склад» закрыто (П3в) | Задача «Склад» |
| `part2/n2_first_text` | Получен первый текст №2 «МОДУЛЬ 4. ОХЛАЖДЕНИЕ. ЧАС.» — запускает кризис модуля №4 (П4) | Текстовый канал №2 |
| `part2/module4_crisis_resolved` | Кризис модуля №4 закончен: охлаждение настроено, с химпротоколом или без (П4–П6) | Кризис модуля №4 |
| `part2/v2_done` | Печать Горна восстановлена, герой вышел из сна V2 (П6) | Сон Боузера V2 |
| `part2/n2_reply` | Состоялся ответ №2 на посту (П7) | Текстовый канал №2 |
| `part2/finale` | Финал части: модуль №3 теряет стабильность, доступ выдан (П9) | Финал части 2 |
| `part2/dream_trace_2` | Герой увидел табличку «2» в межсонье (первый выход через врата); табличка записана в журнал | Межсонье (#228) |
| `part2/n2_believed` | Герой поверил предупреждению №2, кризиса не было — межсонье показывает табличку с затянутой трещиной | Кризис модуля №4 (пока не ставится) |
| `part2/chem_protocol_fired` | Герой медлил, сработал химпротокол — межсонье показывает табличку, отвёрнутую к стене | Кризис модуля №4 (пока не ставится) |
| `part2/n2_trust` | Доверие к №2, число (`GameState.set_flag(flag, value)`); условиями StateRules не сравнивается | Решение «поверить / проверить», порядок направлений |

Межсонье (#228) бывает при каждом выходе из сна, включая первый, и выбирает отголоски условиями StateRules по этим флагам: например, первый выход — `{"not_flag": "part2/recovery_map"}`, после первого текста №2 — `{"flag": "part2/n2_first_text"}`. Флаг `dream/returned/<модуль>` ставится в момент выхода и для выбора отголоска не подходит: он истинен уже при первом выходе. Флаги показанных отголосков межсонье заводит само: `interdream/shown/<отголосок>`. Отголоски и их условия — `data/dreams/interdream.json` (формат — `docs/game_design/10-interdream.md`, раздел 7).

## Направление «Склад» (#231)

Набор `objects/storage/storage_kit.tscn` — мастерская и склад техуровня: баллон реагента (`item_reagent_cylinder`, +1 заряд в запас `Containment`), сервисный ключ техгалерей (`item_gallery_tool`: процедуры обслуживания модуля — `Containment.service_seconds`, пока вентиляция, — вдвое короче, `data/containment/modules.json` → `service`) и журнал склада (`storage_log`, ставит `part2/storage_log_read`). Когда взяты оба предмета и прочитан журнал, событие `part2_storage_done` ставит `part2/dir_storage_done`. Запас реагента в начале игры — 0: единственный запасной заряд — этот баллон; перезарядка модуля помечает его израсходованным (`item_reagent_cylinder/used`). Пока набор стоит на полигоне (момент отладки «Часть 2: склад техуровня»); в комплексе его место — мастерская и склад сектора техуровня (`T-WORKSHOP/workshop`, `T-WORKSHOP/parts_store`) после перегенерации.
