# Документы

Каталоги `*.json` с документами, которые герой находит и читает (`objects/documents/document_pickup.tscn`, поле `document_id`). Все файлы загружаются в `DocumentLibrary` и проверяются тестом `tests/opening/cases/document_case.gd`.

```json
{
  "documents": {
    "staff_memo_anomaly": {
      "title": "ПОРЯДОК ДЕЙСТВИЙ ПРИ АНОМАЛЬНОЙ УГРОЗЕ",
      "meta": "Памятка персонала · аварийный блок",
      "body": "Первый абзац.\n\nВторой абзац.",
      "on_read": [{"set_flag": "read_staff_memo"}]
    }
  }
}
```

- `id` (ключ) уникален во всех файлах.
- `title` и `body` обязательны; `meta` — строка под заголовком (тип, место, дата).
- `journal: false` — текст осмотра (панель, табличка): не попадает в журнал; подключается к `Interactable` полем `inspect_text_id`.
- Оформление бумаги (`docs/ui/style-guide.md`, «Бумага»), все поля необязательны:
  - `form` — шапка формы: `{"office": "служба", "number": "номер формы", "copy": "экземпляр"}`;
  - `stamps` — штампы в правом верхнем углу, например `["ДСП"]` (ДСП, СЕКРЕТНО, ПОГАШЕНО, КОПИЯ);
  - `note` — карандашная пометка персонала внизу листа;
  - `handwritten: true` — весь лист написан от руки (записки персонала);
  - вымарка — символы `█` прямо в тексте (`Ответственный: ████.`), они печатаются чёрными плашками.
- `on_read` — действия из `data/terminals/README.md`, выполняются при первом прочтении.
- Прочитанные документы попадают в журнал (клавиша `J` или «Журнал» в паузе) в порядке прочтения и сохраняются вместе с `GameState`. Журнал — рукописный блокнот героя (#223): заголовок документа там переписан обычным регистром.

> Экспорт: добавьте `data/*` в фильтр не-ресурсных файлов пресета.
