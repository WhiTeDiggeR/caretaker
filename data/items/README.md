# Предметы при себе

Каталог `items.json` — что герой носит с собой (#223). Предмет не используется и не выбрасывается руками: он срабатывает сам в нужном месте (ключ у замка, лом у плиты). Взятый предмет — это флаг `GameState` (`KeyPickup.flag`, `CrowbarPickup.flag`, `Interactable.sets_flag`), поэтому он сохраняется вместе с игрой. Загружается в `ItemCatalog` и проверяется тестом `tests/opening/cases/document_case.gd`.

```json
{
  "items": {
    "item_crowbar": {
      "title": "Пожарный лом",
      "note": "снял с пожарного щита — подденет заклинившую плиту",
      "sketch": "crowbar"
    }
  }
}
```

- Ключ — флаг, который ставит подбор предмета; уникален.
- `title` и `note` обязательны: название и строчка-заметка героя во вкладке «При себе» журнала.
- `sketch` — набросок карандашом (`ItemSketch`): `key`, `crowbar`, `card`; другое значение или пусто — общий набросок свёртка.
- При подборе внизу экрана появляется строка «Взято: <title>».
- Порядок во вкладке — порядок в файле.
