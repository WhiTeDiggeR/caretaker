# Ощущения от первого лица (#134)

## Покрытия под ногами

Шаги считаются по пройденному расстоянию (`objects/feel/first_person_feel.gd`). Покрытие
берётся с коллайдера пола или его родителя:

- метаданные `surface` = `concrete` | `metal` | `grate`;
- или группа `surface_concrete` | `surface_metal` | `surface_grate`.

Без метки (и с неизвестным значением) пол считается бетоном. Ползком слышен шорох одежды
(`step_crawl`), на лестнице-скобах — лязг перекладин (`step_ladder`) независимо от покрытия.
Звуки — каталог `data/audio/sfx.json` (`step_<покрытие>`, `land`, `breath`).

Длина шага (м): ходьба 2,0 · бег 2,7 · присед 1,3 · ползком 0,7 · лестница 0,6.

## Камера

Покачивание при шаге, наклон при движении вбок и просадка при приземлении масштабируются
настройкой «Покачивание камеры» (`Settings.head_bob`, 0 % — выключено). Тряска сюжетных
событий (`EventSequence`, шаг `shake`) от этой настройки не зависит.

## Экранные эффекты — `screen_effects.json`

Автозагрузка `ScreenEffects`: `ScreenEffects.play(&"wake_up")`, `stop()`, `is_playing()`.

```json
"id": {
  "seconds": 2.0,            // длительность
  "hold": false,             // true — остаться на последнем ключе до stop() или загрузки
  "tint_color": "#8fe39a",   // цвет оттенка (параметр tint)
  "vignette_color": "#000",  // цвет виньетки
  "keys": [{"t": 0.0, "blur": 1.0, "darken": 1.0}, {"t": 2.0}]
}
```

Параметры ключей (0…1, отсутствующий = 0): `blur`, `darken`, `tint`, `vignette`, `flash`.
Значения между ключами интерполируются линейно.

Подключено: начало новой игры → `wake_up`; газ химического протокола при герое в камере →
`gas` (держится до загрузки); выход из сна через врата → `dream_exit`, выброс (смерть,
пробуждение) → `dream_eject`. `dream_hit` — для урона во сне (подключается к бою #127).
