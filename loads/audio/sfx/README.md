# Звуки-заглушки систем начала игры (#126, шаги и дыхание — #134, звук сна Боузера — #201)

Происхождение: все файлы синтезированы скриптом `tools/audio/make_sfx.py` (синусы, меандр,
отфильтрованный шум) с фиксированным зерном генератора; сторонних источников и записей нет,
лицензионных ограничений нет. Формат: WAV, 22 050 Гц, моно, 16 бит.

Пересобрать: `python3 tools/audio/make_sfx.py`; проверить, что файлы совпадают с рецептами:
`python3 tools/audio/make_sfx.py --check`.

Воспроизведение (шина, громкость, 3D) — `data/audio/sfx.json`, проигрыватель — автозагрузка
`Sfx` (`objects/audio/sfx.gd`). Финальные звуки подменяются в каталоге без правки кода.

`dream_*` (#201): стингеры сна Боузера (`dream_ambush`, `dream_seal`, `dream_gate`,
`dream_chain_hit`) — тот же синтез, своё, без лицензионных ограничений; хранятся в Git LFS
(`docs/LFS.md`). Фон сна по стадиям файлов не имеет: гул синтезируется в игре
(`objects/audio/dream_audio.gd`), чтобы заглушки остались в бюджете 2 МБ.
