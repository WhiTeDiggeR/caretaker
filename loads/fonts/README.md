# Шрифты интерфейса

Задача #143, стиль-гайд — `docs/ui/style-guide.md`. Семь семейств под SIL Open Font License 1.1, все с кириллицей; файлы не изменены, лицензия — `OFL.txt` рядом с каждым семейством, источник, версия и контрольные суммы — `manifest.json`.

Код не ссылается на эти файлы напрямую: роли шрифтов — ресурсы `materials/ui/fonts/*.tres` (`FontVariation`, у вариативных Oswald и Caveat там же задан вес) и константы `UiStyle` (`scenes/ui/ui_style.gd`). Новое начертание — новый файл здесь, запись в манифесте и ресурс роли.

Шрифты не входят в правила Git LFS (`.gitattributes`): `.ttf` хранятся обычными файлами, всего ≈ 4,5 МБ.
