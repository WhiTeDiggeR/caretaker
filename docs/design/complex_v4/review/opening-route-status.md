# Маршрут начала по комплексу v4: состояние и план минимальной починки (#170)

Срез: `team/integration` df9c16ee, 2026-10-12. Цель — пройти **только маршрут начала** (`docs/game_design/01-opening.md`, сцены 1–12),
а не чинить все 32 сектора.

## Коротко

- Генерация как таковая маршрут **не блокирует**: все 32 пакета `gen/` есть, собраны из текущих канонических SVG (sha256 совпадают),
  все лестницы маршрута сгенерированы и встают в шахты, сборка импортируется и проходит headless-проверки.
- Маршрут рвётся в **одном месте данных**: в L-OLD-CORE блок «старый резервный ЦУ + релейная + комната старшего» замкнут —
  к коридору у холла ведёт только окно, двери нет (уже в утверждённом исходном плане). Из-за этого недостижимы сцены 7 и 10.
- Остальное — **решения автора**, а не поломки: где операторская (сцена 10, Р-2), каким путём идти к модулю №4 (сцена 11),
  нужна ли прямая дверь в T-ENERGY для сцены 9, как оформлять сюжетные блокировки (G-05).
- Минимальный путь до проходимого маршрута: одна поправка (дверь ЦУ) → перестройка канонического SVG и манифеста (в облаке) →
  локальная регенерация **одного** сектора L-OLD-CORE у автора → повторный прогон проверки.

Сведения из описания задачи, которые устарели: U-/L-CIRCULATION уже производственные сектора — манифест, каталог сцен, матрица и
`complex_v4_sector_check` рассчитаны на 32 (коммит 420a50de, #95); VT-OLD-STAIR уже сгенерирована (U-turn, восточная сторона,
решение автора в #67), её блокировка в #67 к маршруту больше не относится.

задачей плейтеста (#169). Когда маршрут станет проходимым, CI следует перевести на `-- --strict` (маркер `blocked=0`).

## Вопросы автору

**1. Где закрытая операторская (сцена 10, Р-2)?**

- **A (рекомендую).** L-OLD-CORE, «Комната старшего» рядом с ЦУ (плюс релейная как «разрушенная служебная зона»). Совпадает с Р-2,
  дверь между ЦУ и комнатой уже есть (`door-04`); нужна только общая дверь ЦУ из шага 2. Сцена 11 начинается в старом ядре.
- **B.** U-CONTROL: «Кабинет старшего / аварийные полномочия» + «Основной операторский зал» — точнее всего по тексту канона, но
  далеко от старого ядра (против Р-2), на верхнем этаже (тогда сцена 11 — уже не «LV-L → LV-U») и без выхода в магистраль U:
  нужны поправки U-CONTROL и U-CIRCULATION (E-U04) и регенерация двух секторов.
- **C.** L-OLD-RECEIVING, «Пост управления» старого приёмного зала (через общий доступ старого ядра). Рядом с ядром, но без
  «старшего» и аварийного управления в паспорте.

**2. Каким путём герой идёт к модулю №4 (сцена 11)?**

- **A (рекомендую).** Через главное ядро: коридор L → главная лестница → коридор U → модуль 4 (≈200 м). Геометрия готова,
  совпадает со сводкой «LV-L → LV-U», не трогает завал в холле U-EMERGENCY.
- **B.** Назад по маршруту A и через холл U-EMERGENCY (≈86 м). Короче, но требует, чтобы «проход из холла завален» к этому моменту
  был расчищен — решение по G-05.

**3. T-ENERGY для сцены 9: оставить обход через коридор?**

- **A (рекомендую для минимального пути).** Оставить как в D-28: щитовая и охлаждение — через служебный подход, зал — через
  коридор. Ничего не перегенерировать; при необходимости сократить шаги процедуры.
- **B.** Добавить дверь wing 1,8 зал ↔ охлаждение (стена x −75,22, z ≈8,9…10,7) и дверь щитовая ↔ охлаждение (z 3,82) —
  замкнутый круг ремонта внутри энергоблока; +1 сектор в регенерации.

**4. Блокировки (G-05)** — какие двери/завалы закрыты на каждом шаге сцен 3–11. Рекомендация: не трогать геометрию, вести как
состояния дверей/объектов в геймплее (отдельная задача по сцене, не по комплексу).
