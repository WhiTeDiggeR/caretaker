  - **B.** Лестница внутри холла (вырезать из холла 8×10 м).
  - Рекомендация: **A**.
  - Пример: `examples/old_stair_L.png`

- **L-OLD-CORE-02** [библия] Комната старшего оператора — закрытая операторская с ключом. Нет «разрушенного служебного прохода», дверь не помечена закрытой (G-05, G-12).

  - **B.** Дверь заперта, пролом отсутствует (ключ в зале).
  - Рекомендация: **A**.
