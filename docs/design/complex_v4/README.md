# Комплекс v4 — канонические источники генерации

Версия 4 хранит **метрические SVG для генератора** (`plans/generation/`), построенные из **утверждённых планов v3**
(`docs/design/complex_v3/plans/sectors` и `plans/overview`) без изменения их геометрии. Старые SVG, выведенные из handoff JSON, удалены.

- Построение: `python tools/complex_v3_regeneration/build_canonical_from_approved.py` (привязка к общим планам — `approved_registration.json`).
- Масштаб и положение берутся только из общих планов этажей (линейки 9 px/м у U/L, 8 px/м у T); оси масштабируются независимо.
- Элементы, добавленные в утверждённые планы позже (пилоты лестниц), в построении не участвуют.
- Магистрали, соседние сектора, мебель и оборудование записаны как `ignore`.
- Ревизия: `review/README.md` — статус сквозных вопросов и по одному файлу на сектор (`review/sectors/`); все решения — `review/decisions.md` (D-01…D-42), применены в `approved_registration.json`.
  Коридоры и магистрали U/L/T принадлежат секторам U-/L-/T-CIRCULATION; канонических SVG 32.
- Источник правды по смыслу — `docs/world/` и утверждённые планы v3. `handoff/`, `complex_map_v2.md` и планы v1/v2 не используются.
