# Комплекс v3 — планы и визуальные материалы

Материалы разложены по назначению и этажам:

- [`plans/overview/`](plans/overview/) — общие планы этажей; утверждённая версия лежит в `current/`, прежние изображения — в `archive/`;
- [`plans/sectors/`](plans/sectors/) — детальные планы отдельных зон по верхнему, нижнему и техническому этажам;
- [`sketches/`](sketches/) — атмосферные и предметно-пространственные наброски по этажам и зонам;
- [`ledgers/`](ledgers/) — реестры секторов и обязательных связей;
- [`validation/`](validation/) — протоколы и отчёты проверки;
- [`handoff/`](handoff/) — машинный пакет для сборки комплекса в движке.

Актуальные общие планы:

- [верхний этаж](plans/overview/upper/current/upper-floor-functional-plan-v4.html);
- [нижний этаж](plans/overview/lower/current/lower-floor-functional-plan-revised.html);
- [технический этаж](plans/overview/technical/current/technical-floor-functional-plan-v3.html).

Черновые изображения используются для поиска атмосферы и визуального языка начальной части комплекса. Они не фиксируют точную геометрию помещений.
