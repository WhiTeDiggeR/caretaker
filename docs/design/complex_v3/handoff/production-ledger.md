## Fixed

- Два основных этажа и нижний технический уровень.
- Шесть автономно разнесённых камер.
- Камеры, процедурные, аппаратные, склады, щитовые и иные непроходные комнаты не являются транзитом.
- Главный пассажирский и тяжёлый грузовой контуры раздельны.
- Камера 1 сохраняет историческое исключение: один совмещённый перестроенный порог.
- Камеры 3–6 используют автономный модуль с раздельными пассажирским и грузовым порогами.
- Сохраняются опоры `A-ROUTE-A`, `A-OLD-STAIR`, `A-SERVICE-STAIR`, `A-MAIN-CORE`, `A-EAST-STAIR`, `A-FREIGHT-LIFT` и полоса `A-HEAVY-SPINE`.
- Поверхность недоступна игроку.
- Стиль B: непрозрачные непересекающиеся помещения, отдельные непрерывные коридоры, минимальные однозначные подписи.

## Inferred for metricization

Следующие значения являются инженерными предположениями handoff и могут корректироваться после прохода блок-аута без изменения топологии:

| Параметр | Значение stage 1 | Допустимая первичная корректировка |
|---|---:|---:|
| Высота верхнего чистого пола | `Y = 0.0 m` | фиксируется как world datum |
| Высота нижнего чистого пола | `Y = -6.0 m` | `±0.5 m` |
| Высота технического чистого пола | `Y = -11.5 m` | `±0.5 m` |
| Типовая чистая высота помещений | `3.4 m` | `3.2–4.0 m` |
| Тяжёлые/камерные объёмы | `5.0 m` | `4.5–6.0 m` |
| Главный пассажирский коридор | `4.0 m` | `3.6–4.5 m` |
| Главный технический коридор | `5.5 m` | `5.0–6.0 m` |
| Тяжёлая магистраль | `7.5 m` | `7.0–8.0 m` |
| Типовая дверь | `1.2 × 2.4 m` | по паспорту сектора |
| Герметичная дверь | `1.8 × 2.8 m` | по паспорту сектора |
| Тяжёлые ворота | `4.5 × 4.5 m` | по грузовому габариту |
| Допуск общей межэтажной оси | `0.25 m` | не увеличивать без причины |

## Unknown, resolved at stage 2

- Точные толщины стен по строительным эпохам.
- Точные размеры каждого дверного и грузового проёма.
- Геометрия маршей, площадок и просветов каждой лестницы.
- Уклон, сечение и длина старого наклонного тоннеля.
- Точные рабочие обходы оборудования и радиусы разворота платформ.
- Границы скрытых конструктивных объёмов между секторными планами.
- Итоговые точки спавна, навигационные области и игровые collision margins.

Эти неизвестные не меняют общую топологию и не блокируют согласование этапа 1. Они блокируют статус `ready-for-3d` до завершения этапа 2.
