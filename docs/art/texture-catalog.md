# Каталог текстур и материалов

Общий набор, который закрывает все пропы В1 и большую часть комплекса. Сначала проверяем готовое (`loads/` и скачивание, см. `sourcing.md`), недостающее рисуем скриптом `tools/props/make_textures.py`.

Формат: `albedo` (sRGB), `normal` (OpenGL), `orm` (R = occlusion, G = roughness, B = metallic). Все бесшовные, 1024².

## 4. Правила сборки

- Тайловые материалы собираются в Godot-ресурс `materials/props/<id>.tres` с триплапланарным отключением: UV уже в мировом масштабе из Blender.
- Для «героев» допускается запекание уникального грязевого слоя, но не больше 2048².
- Источник каждой текстуры — запись в `tools/props/manifest.json`.
