## Открытые вопросы

| № | Вопрос | Варианты | Рекомендация |
|---|---|---|---|
| В-1 | Останки: что видно из-под плаща | **а.** Кости кистей и голеней (как сейчас, Д-3 «б») · **б.** Белая перчатка на кости — сильнее «герой», выше риск О-10 · **в.** Всё под плащом | **а** |
| В-2 | Страж: анимация | **а.** Авториг сервиса генерации по A-позе + клипы стойка/шаг/удар · **б.** Без рига, как сейчас (сдвиг и наклон `DreamEnemy`) · **в.** Риг вручную в Blender | **а**; если авториг ломает шипы панциря — **в** |
| В-3 | Херобрин: как улучшать | **а.** Скрипт: блочная форма 8/12/4, фаски, новая детальная скин-текстура, без генерации · **б.** Генерация «воксельного» персонажа · **в.** Полуреалистичный гуманоид с блочной головой | **а**: генераторы плохо держат ровные кубы, а образ — именно в них |
| В-4 | Спящий сотрудник | **а.** Генерация одного меша + 2–3 текстуры, подключение после #224 · **б.** Улучшить примитив скриптом · **в.** Оставить | **а**, последним в очереди |
| В-5 | Останки в комплексе | **а.** Не добавлять · **б.** Останки учёного у капсулы №3 (канон) — отдельная сюжетная задача | **а**, сюжет решить отдельно |
| В-6 | Статуи стражей Д-02 | **а.** Тот же меш С-01 в камне · **б.** Не делать | **а**, после С-01 |

Очерёдность пакетов этапа 2: С-01 → Н-01 → сотрудник; Херобрин — скриптом (В-3).
