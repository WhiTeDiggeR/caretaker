# Тексты начала игры: размещение и флаги

Сводка текстов задачи #106 для сборки сцены начала (`docs/game_design/01-opening.md`). Сами тексты лежат в данных:

- `data/documents/opening.json` — документы журнала и тексты осмотра (`journal: false`);
- `data/terminals/opening_old_cp.json`, `opening_succession.json`, `opening_module4_post.json` — программы терминалов.

Тексты — **предложения** для утверждения автором. Ограничения, которые они соблюдают:

- не раскрывают побег объекта №1, его личность и назначение камеры №1 — только следы («Клеть», «Усиление», смятые ворота, «перегрузка энергоконтура»);
- не раскрывают личность №2 — только намёк в журнале архива (дело «Перенос» изъято);
- показывают неоднозначность происхождения комплекса двумя противоречащими листами паспорта;
- не называют имён персонала (Р-6) и героя (Р-7): герой — заглушка «ОХРАННИК, ТАБ. № 2-117», остальные имена закрыты «████»;
- не сообщают масштаб комплекса: монитор модулей показывает только модуль 4 и строку «прочие модули — засекречено / нет связи»;
- не содержат видений Херобрина в реальности (Р-8): помехи и бессонница упомянуты только как прошлые записи.

## Флаги начала игры

| Флаг / допуск | Кто ставит | Кто читает |
|---|---|---|
| `gen_diagnosed` | щит генератора (`sets_flag`) | процедура пуска, шаг 1 |
| `generator_started` | процедура пуска | пульт старого ЦУ |
| `item_crowbar` | лом с пожарного щита (`CrowbarPickup`) | пролом стены (`BreachWall`) |
| `opening/senior_breach_hits`, `opening/senior_breach_open` | удары ломом по трещине | стена-пролом (состояние сохраняется) |
| `senior_key_taken` | подбор ключа в операторской | терминал ОП-1 |
| `caretaker_assigned`, допуск `caretaker`, `module_4` | протокол преемственности | двери поздних секторов, модуль 4 |
| `module4_ready` | чек-лист поста модуля 4 | кресло погружения (будущая задача) |
| `journal/read` | `DocumentLibrary` | журнал (J) |

## Цели (объективы)

`start_generator` «Запустить главный генератор» → шаги процедуры пуска (подсказки шагов) → `find_operator_room` «Найти закрытую операторскую» → `reach_module_4` «Добраться до модуля 4» → `enter_dream` «Занять кресло погружения».

Цели сцен 1–6 («Выбраться из аварийного блока», «Добраться до резервного пункта управления») задаёт сценарий сцены начала при сборке.
