**Сюжетные рельсы после первого сна (`06-story.md`, `04-chronology.md`).**
- Линия №2: следы в снах героя («2», табличка, силуэт) → поиск камеры → образы через терминал → ремонт → короткий текст → **первое сообщение — проверяемое предупреждение** → помощь ради доверия и подключения к поздним системам → модернизация → вход в сон №2 → видеозапись → признание → сделка.

- Хаб после линейного начала становится **полуоткрытым**; кризисы — на этапах прогресса, а не глобальный таймер.
- Посещения: Боузер 3–4, Херобрин 2–3, №2 1–2.
- Финал: узел восстановлен, но диагностика блокирует переход и пробуждение персонала → три исхода (жертва героя / жертва сотрудника / скрытое решение из трёх частей) + открытая судьба героя.

**Системы давления (канон `02-world-rules.md`).**
- Прогноз пробуждения только у сна, потерявшего стабильность; идёт, пока герой в другом месте.
- Истечение → аварийная фаза → химпротокол модулей №3–6: герметизация, газ, ограниченный реагент, последнее окно. Повтор только после вентиляции и перезарядки. Газ усыпляет и героя; в кресле его может разбудить №2.
- Боузер и Херобрин не должны проснуться вместе.
- Смерть во сне ускоряет пробуждение хозяина.

**Принятые решения начала, важные для части 2.** Р-5 (в комплексе нет врагов), Р-6/Р-11 (5 спящих сотрудников, 20 капсул), Р-7 (имя героя — заглушка), Р-8 (видения Херобрина только в прологе — сон Херобрина на старте стабилен), Р-13 (время 1 : 15), Б-11 (порядок визитов по флагам), Б-12 (следы прежних операторов 1–2 за визит).
