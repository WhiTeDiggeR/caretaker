# Часть 2: сравнение вариантов и вопросы автору

## Сравнение

| Критерий | A «Голос из камеры №2» | B «Две угрозы» | C «Полуоткрытый комплекс» |
|---|---|---|---|
| Суть | Тихое расследование, линия №2 по шагам канона | Кризис модуля 3 сразу, тело учёного, сон Херобрина | Три направления на выбор, кризис по прогрессу |
| Темп после первого сна | Спокойный → кризис в середине | Резкий с первых минут | Свободный → кризис по этапу |
| Новый сон | Боузер V2 «Горн» | **Херобрин V1** | Боузер V2 «Горн» |
| Химпротокол | Только при «проверить» (+ учебный тест) | Почти гарантирован | Вероятен; последствия зависят от порядка |
| Правило «3 и 4 не вместе» | Регламент + финал | Игровая ситуация с двумя прогнозами | Регламент + финал |
| Первое предупреждение №2 | Центральное событие | Мелко, в конце | Центральное (в C′ — всегда до кризиса) |
| Соответствие канону | Высокое | Среднее: сжат порядок линии №2, рано тратится учёный | Высокое: полуоткрытый хаб и кризис по этапу |
| Решения игрока | Поверить/проверить | Газ или сон; кому отдать баллон | Порядок; поверить/проверить |
| Риск | Монотонные ремонты | Перегруз, дорого | Расползание темпа, комбинации |
| Объём | **S–M** | **L** | **M** (C′ — S–M) |

## Рекомендация

**C′** — полуоткрытый комплекс, где кризис модуля 4 запускается первым текстом №2.

- Канон: «после почти линейного начала комплекс становится полуоткрытым», кризисы — на этапах прогресса.
- Берёт лучшее из A: проверяемое предупреждение №2 всегда перед кризисом.
- Откладывает дорогой сон Херобрина на часть 3, где правило «не вместе» работает в полную силу.
- Работы делятся на независимые задачи: три направления, ветка «Горн», текстовый канал №2.

Если нужно ещё дешевле — **A** (тот же сюжет, без свободы порядка). **B** — только если важно показать Херобрина уже во второй части.
